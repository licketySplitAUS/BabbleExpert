## What's new in Babble Expert 3.4.0

- **Gentler connection recovery:** pages opened by Expert quietly retry temporary connection failures twice before suggesting Refresh or Retry. Technical network errors stay out of the page. Background update checks retry temporary failures sooner without error popups. Slow or briefly frozen pages can recover without an automatic reload interrupting your entries.

- **Optional Babble username link:** Send lickety a message has a separate username box and an initially unticked permission checkbox. After confirmed delivery, Expert remembers the link for future reports while usage sharing is enabled. Remove the link on that page at any time. Contact names and email addresses remain separate from reporting identity.

- **Fireworks notifications:** with usage sharing enabled, automatic completion fireworks now send one Expert notification, as do manual previews and replays. The embedded Clues page defers to Expert, so its separate browser-completion report is suppressed. Reports contain no puzzle identifier, entered words or completion counts.
- **Possible dice conflicts in Resources:** a light gray background identifies words whose letters conflict with the reference Big Boggle dice described on Lickety Info. Hover for the reason. These are hints, not confirmed Babble restrictions; words remain clickable and confirmed result colours take priority. Classification is limited to displayed rows and cached to keep large lists responsive.
- **Keep moving through unfinished clues:** with Clues set to **Off** and a word-list Resource open, completing the selected clue automatically selects the next unfinished clue and positions both panes. Resources changes word length when needed. Other found words and duplicate or rejected attempts do not skip the current clue.
- **Progress recorded automatically:** the personal progress journal records locally by default, building up puzzle statistics as you play. This update turns recording on once for existing installations too, including those previously set to off. Any later choice to pause is remembered. Open **Options → Personal progress journal** to explore your history, pause recording, export CSV or clear it. Earlier play cannot be reconstructed.

## Downloads and updates

The installed version is **V3.4.0.0**. Windows users can update from Options or the official Setup download. Mac users replace Babble Expert in Applications using the universal DMG, supporting Intel and Apple Silicon. Existing settings and logins are preserved. Progress recording is enabled by this update; you can pause it at any time in Options → Personal progress journal.

Both installers remain unsigned by the maintainer's choice. Follow the existing installation guide for system prompts.
