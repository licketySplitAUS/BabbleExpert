## What's new in Babble Expert 3.2.0

- Rainbow grid highlighting traces your word as you type, using the remaining clue words to help choose between duplicate letters. **Highlight entry on grid** is enabled by default and can be switched off in Options.
- **Fun Word Play** and **Chill Vibes** bring animated word art and gentle flowing colour to the right-hand pane, responding to your typing and submitted words.
- Finishing a grid starts a 60-second fireworks celebration, with varied shells, fountains, deep booms and transparent effects over the existing Clues and PlayBabble pages. Click the fireworks page to replay, or use **Hide** to dismiss it.
- **Lickety Info** now opens a new page about licketySplitAUS and links to other Babble experiments.
- Optional usage notifications help improve Babble Expert. With permission, they report the app version, menu choices, session duration, operating system, approximate country and a random installation ID. They never include entered words or chat. Sharing can be turned off in Options; existing opt-in users are asked again about the expanded information.

## Downloads and updates

- **Windows:** run `BabbleExpert-Windows-Setup.exe`. Existing updater-enabled installations will download the new version and install it when Babble Expert closes.
- **Mac:** open `BabbleExpert-macOS.dmg` and replace Babble Expert in Applications. The universal app supports both Intel and Apple Silicon Macs.

The installers are unsigned, as with previous releases. Windows may show SmartScreen; on Mac, use the existing Open / Open Anyway steps if macOS blocks the app.
