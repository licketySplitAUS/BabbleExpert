## What's new in Babble Expert 3.2.13

- **Helpful balloon hints:** readable captions explain Expert’s toolbar, resize bars and Add controls after a one-second hover or keyboard focus. Options → Show helpful hints turns them on or off. Existing hidden-hint preferences are preserved. Captions dismiss when you click, type or press Escape.
- **Keyboard resizing:** click either resize bar, then use Left/Right; hold Shift for larger steps, or Home for minimum width. A blue outline shows which bar has keyboard focus. This also works after using the Babble pane and when sides are switched.
- **Reliable startup:** Expert appears immediately. Repeated clicks reuse and restore its window. Local failures have bounded recovery and diagnostics.
- **Tour on demand:** the guided tour opens only from Help or Options. Other helper windows recover safely if loading fails.
- **Safer transfers:** bulk transfers stop when the puzzle changes; uncertain operations keep recoverable entries. Hung page operations and update checks have deadlines.
- **Startup notifications:** opted-in installations send one anonymous startup notice per launch, alongside the existing session-ending report.
- **Easier support:** Help can copy a technical support summary. Optional diagnostics prioritise important failures and omit entered words, chat, page URLs and local paths.
- **Readable controls:** Options can enlarge the toolbar. Pane dividers support arrow keys, Shift for larger steps and Home for minimum width. Page zoom remains separate.
- **Browser tools:** reload, return home, clear cached files while keeping logins, and deliberately reset a site's data from Options.
- **Updated runtime:** Electron 44.9.3 and reviewed dependency updates. Release builds verify manifests, checksums and packaged startup.

## Downloads and updates

Windows users can update from Options or the official Setup download. Mac users replace Babble Expert in Applications using the new DMG. Both installers remain unsigned by the maintainer's choice. Follow the existing installation guide for system prompts.
