## What's new in Babble Expert 3.7.0

- Improved performance for slower machines.
- Celebrations now show by default, including on slower machines. Turn them off in **Options → Show celebration animations**.

## Downloads and updates

The installed version is **V3.7.0.0**. Windows users can update from Options or the official Setup download. Mac users replace Babble Expert in Applications using the universal DMG, supporting Intel and Apple Silicon. Existing settings, logins and journal history are preserved.

Both installers remain unsigned by the maintainer’s choice. Follow the existing installation guide for system prompts.
