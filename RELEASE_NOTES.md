## What's new in Babble Expert 3.2.1

- **More reliable Lickety Add colours:** green means Babble confirmed the word, amber means already entered or not yet confirmed, and red means an explicit rejection. Rapid entries are processed in order, and a stale Clues page no longer turns an accepted word red.
- **Grid matching uses the letters, not the puzzle number.** Self Serve Clues automatically requests Grab Grid when its grid differs from PlayBabble. Bulk word transfer is blocked when grids differ or cannot be checked.
- **Less clutter:** status stays in the compact toolbar. Recent entries are available through **Entries…** in a separate dialog, without taking space from the puzzle. Reloading original Clues restores checked words only when the grid still matches, without a confirmation prompt.
- **Friendlier updates:** the installed app checks at startup, every 30 minutes and when returning after an overdue check. Windows downloads quietly and offers **Update now** or **Later**. Update buttons appear only when something new is available.
- **Optional Help:** use **Help** or **F1** for a short three-step guide to clue sources, Lickety Add colours and word transfer, plus keyboard shortcuts. Nothing opens automatically.
- Babble Expert is now available under the **MIT License**, with public security, privacy and code-signing information.

## Downloads and updates

- **Windows:** run `BabbleExpert-Windows-Setup.exe`. Existing updater-enabled installations will download this release and install it when Babble Expert closes; the new update prompts apply after upgrading.
- **Mac:** open `BabbleExpert-macOS.dmg` and replace Babble Expert in Applications. The universal app supports both Intel and Apple Silicon Macs.

The installers are unsigned, as with previous releases. Windows may show SmartScreen; on Mac, use the existing Open / Open Anyway steps if macOS blocks the app.
