# Security

To report a suspected vulnerability in Babble Expert, email
[Lickety Split](mailto:licketySplitAUS@gmail.com). Include the app version,
operating system, steps to reproduce and the likely impact. Do not include
passwords, API tokens or other people's private information.

Please report security-sensitive details privately rather than in a public
GitHub issue. There is no guaranteed response time. Fixes are distributed in
new releases; older versions do not have a separate security-maintenance branch.

For ordinary bugs and feature requests, use the repository's GitHub issues.
Issues in PlayBabble, clue websites or other third-party services should also
be reported to the relevant service owner.
